WhatsApp Web Monitor

Como configurar o monitoramento?

Passo 1 → Clique em "Adicionar Monitoramento" e preencha os dados da conversa:

  • Grupo ou contato: Copie e cole o nome exatamente como ele aparece no WhatsApp Web.
  • Contatos (opcional): Em grupos, adicione os participantes cujas mensagens devem ser consideradas. Se a lista ficar vazia, todos os contatos serão considerados.
  • Palavras-chave: Adicione as palavras ou frases que devem iniciar uma resposta.
  • Respostas: Adicione uma ou mais respostas. Quando uma palavra-chave for encontrada, a extensão selecionará uma resposta da lista.
  • Períodos (opcional): Defina datas ou horários para limitar o envio das respostas.

Ao concluir o cadastro, clique em "Salvar".

Passo 2 → Abra o WhatsApp Web no navegador.

Passo 3 → Abra a conversa que deseja monitorar.

Passo 4 → Ative o "WhatsApp Web Monitor" na tela do WhatsApp Web e aguarde a chegada das mensagens. O monitoramento continuará funcionando quando outra aba estiver ativa, desde que o WhatsApp Web permaneça aberto.

Observação: É possível ativar ou desativar os monitoramentos a qualquer momento. Lembre-se de salvar as alterações.
