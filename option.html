WhatsApp Web Monitor

Primeiros passos

Como usar essa Extensão?

  1. Passo 1 → Clique em "Adicionar Monitoramento" para inserir um novo registro do que deseja monitorar. O software precisa das seguintes informações para funcionar:

    • Nome do Contato: É utlizado comparação direta, isso significa que se a escrita não for exatamente igual ao do seu WhatsApp pode não achar o contato certo (por isso recomendamos copair e colar o nome do contato).
    • Lista de Palavras-chave: A lista de palavras ou frases que serão procuradas nas mensagens. Podem ser colocadas palavras únicas ou frases, lembrando que acentos ou ç não são levados em conta. (Exemplo: "arco-íris" ou "arco-iris" serão a mesma palavra para comparação)
    • Lista de Respostas: O WhatsApp detecta tem um sistema de detecção de bots. Então para disfarçar o uso dessa extensão será sorteada uma resposta da lista de respostas. Você pode colocar uma única resposta se preferir, mas esteja ciente do risco.
    • Opcional: Essa extenção tambem tem a opção disponível de escolher a data ou horário em que as respostas são enviadas.

    Assim que terminar clique em "Salvar".

  2. Passo 2 → Conecte o seu WhatsApp Web no navegador.

  3. Passo 3 → Abra a conversa do contato ou grupo que deseja monitorar.

  4. Passo 4 → Ative o "WhatsApp Web Monitor" na tela do seu WhatsApp Web e espere as mensagens chegarem. O monitoramente funciona mesmo a tela esteja em outra gruia, então se sinta livre para usar o comportamenteo livremente, desde que o WhatsApp Web esteja aberto.

PS: É possível ativar/desativar os grupos a serem monitorados em qualquer momento, apenas lembre de salvar!
