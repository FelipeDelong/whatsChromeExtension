# Changelog

All notable changes to WhatsApp Web Monitor are documented here.

## [1.0.0] - 2026-08-15

### Added

- Added a theme selector with predefined themes.
- Added loading feedback while monitor and configuration operations complete.
- Added validation feedback for missing required fields.
- Added monitor ON/OFF controls.

### Changed

- Refined the responsive options, popup, and monitoring configuration interfaces.
- Improved keyword matching and monitor lifecycle handling.
- Updated the Portuguese setup instructions.
- Updated the bundled SweetAlert2 release to 11.26.25.

### Fixed

- Corrected grammar and syntax in the instructions.
- Improved asynchronous tab communication and duplicate-loop protection.
- Improved validation of invalid and duplicate date/time ranges.
